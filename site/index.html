映像与自定义文件

根据设备支持的格式输出固件与校验值。

根分区用于系统和软件，升级后的数据保留行为依设备与升级方式而定。电视盒、任意内核切换和 EMMC 专用打包尚未接入。

初始化 Shell

脚本嵌入 /etc/uci-defaults，仅在路由器首次启动时执行。需使用私有构建仓库。

自订文件包

ZIP / TAR.GZ / TGZ / 7Z，最大 12 MiB。普通文件按根目录结构覆盖；Kwrt 支持兼容的 IPK，在路由器首次开机安装，不在构建主机运行包内脚本。仅使用你信任的包；核心包、内核模块和 APK 请从软件源选择。

连接你的构建仓库

ChatGPT 的 GitHub 连接不会自动传给网页。可使用临时授权令牌直接操作，也可不填令牌，导出配置后在 GitHub 手动运行。

直接构建需要 Actions 读写权限；上传文件另需 Contents 读写权限。令牌不进入模板、配置文件、网址或浏览器储存。

开始这次构建
