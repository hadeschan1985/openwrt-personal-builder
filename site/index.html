连接你的构建仓库

ChatGPT 的 GitHub 连接不会自动传给网页。可使用临时授权令牌直接操作，也可不填令牌，导出配置后在 GitHub 手动运行。

直接构建需要 Actions 读写权限；上传文件另需 Contents 读写权限。令牌不进入模板、配置文件、网址或浏览器储存。

构建配置

密码通过仓库 Secrets 引用，不包含在下方 JSON。自定义脚本和文件路径可能包含私人内容。
