# 当前交付范围

[日常使用](USAGE.md) · [本轮测试与证据](RELEASE-10.md)

本机项目位于 E:\OpenWrt-Personal-Builder。采用公开网页仓库与私有构建仓库，GitHub Pages + Actions，无 VPS、会员或新增长期账户权限。

| 项目 | 当前范围 |
|---|---|
| Kwrt 设备目录 | 与原站当前公开目录匹配，865 档案、24 平台 |
| 配置审计 | 全部 865 档案按自己的构建器、格式及配置校验 |
| 暂停构建 | N1 缺少无线校准包；玩客云实际构建包 SHA256 与公布值不符 |
| ROOTFS 专用 | 两个档案仅有根文件系统，不能当成整机刷机映像 |
| 实际设备测试 | 非 x86 平台代表型号编译和文件校验；不等于逐台实机启动 |
| x86 | 本次各输出可执行隔离虚拟机启动、后台登录及本地服务验收 |
| 后台账号 | 新配置暂用 root / root，可切换私有仓库自定义密码 |
| 下载 | 每个固件文件独立下载；日志、清单和校验报告分开 |
| 保存 | 普通产物七天，手动私有收藏最多五版，不自动删除 |
| 授权异常 | 失效停止轮询；限流等待恢复；不自动重复提交 |
| 自动批准上游更新 | 官方稳定版及 Kwrt 25.12 x86/64 |
| 其他平台上游 | 固定校验值，变化时暂停；全平台自动更新批准尚未完成 |

当前不提供任意内核或 DTB 切换，不承诺任意软件组合均可安装。实体 USB/WWAN、无线射频、代理线路和 ESXi 宿主机仍需对应硬件环境验证。

旧版报告只作为历史证据。此前“Kwrt 仅 x86”“默认必须设置强密码”等描述已由本轮范围及你指定的临时 root 密码选项替代。
