# 当前交付范围

[日常使用](USAGE.md) · [本轮测试与证据](RELEASE-12.md)

本机项目位于 E:\OpenWrt-Personal-Builder。采用公开网页仓库与私有构建仓库，GitHub Pages + Actions，无 VPS、会员或新增长期账户权限。

| 项目 | 当前范围 |
|---|---|
| Kwrt 设备目录 | 与原站当前公开目录匹配，865 档案、24 平台 |
| 配置审计 | 全部 865 档案按自己的构建器、格式及配置校验 |
| 特殊资源修复 | N1 校准包、玩客云正确作者构建器及 USB-burn 打包已完成云端验证；新验收版本启用，旧固定版本保留历史状态 |
| 电视盒子 | 209 个资源匹配型号、三个固定内核、自动 DTB；四组代表组合实际打包与回读通过，不等于 209 台实体测试 |
| ROOTFS 专用 | Wavlink WL-WN573HX3 仅有根文件系统；电视盒子可选择 ROOTFS 或按型号打包完整 Btrfs 磁盘 |
| 实际设备测试 | 非 x86 平台代表型号编译和文件校验；不等于逐台实机启动 |
| x86 | 本次各输出可执行隔离虚拟机启动、后台登录及本地服务验收 |
| 后台账号 | 新配置暂用 root / root，可切换私有仓库自定义密码 |
| 下载 | 每个固件文件独立下载；日志、清单和校验报告分开 |
| 保存 | 普通产物七天，手动私有收藏最多五版，不自动删除 |
| 授权异常 | 失效停止轮询；限流等待恢复；不自动重复提交 |
| 自动批准上游更新 | 官方稳定版及 Kwrt 25.12 x86/64，通过引导和登录回归 |
| 多型号上游 | 每日检查，发生变化的平台逐一编译验收；本轮 23 个非 x86 平台通过、0 个暂停，新版本 kwrt-25.12-20261027-8ca6d8b4 |
| 网页发布 | 完整基线快照离线审计，避免滚动软件源变化阻止部署 |
| 历史验收配置 | 读取对应历史目录和内容校验值，不自动换成新版本 |

盒子内核限定为已核验的固定版本，DTB 随型号绑定；不接受任意内核/DTB 下载地址，也不承诺任意软件组合均可安装。实体 USB/WWAN、无线射频、代理线路和 ESXi 宿主机仍需对应硬件环境验证。

旧版报告只作为历史证据。此前“Kwrt 仅 x86”“默认必须设置强密码”等描述已由本轮范围及你指定的临时 root 密码选项替代。
