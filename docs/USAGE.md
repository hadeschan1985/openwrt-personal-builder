# 个人工作台使用方法

本文是当前使用入口。历史报告中的设备范围、测试数量和旧链接以本文及 [当前交付范围](DELIVERY.md) 为准。

[打开工作台](https://hadeschan1985.github.io/openwrt-personal-builder/?v=20261027-1) · [私有构建记录](https://github.com/hadeschan1985/openwrt-personal-builds/actions/workflows/build.yml)

## 选择设备和软件

1. 在“固件版本”选择 Kwrt 全设备固定构建器，可搜索原站当前目录中的 865 个设备档案、24 个平台。官方 OpenWrt 目录单独保留，不混用软件源。
2. 输入型号，也支持红米、小米、华硕、网件、斐讯、树莓派等常用中文品牌和型号组合。
3. 选择出厂包移除、常用软件、代理插件、主题和网络设置。可用包按设备架构列出，灰色表示当前索引缺包；实际构建还会检查依赖和冲突。
4. 查看设备自己的固件格式。默认优先 sysupgrade；factory、SD 卡、EMMC 等格式只在该设备提供时出现。需要多个格式可多选，下载仍逐个分开。

目录收录不表示本项目测试过这台实体设备。N1 和玩客云当前暂停，页面显示各自原因；两个 ROOTFS 专用档案不提供直接刷机映像。切勿只凭相似型号名称选择固件。

## 后台账号与验收模式

- 用户名固定 root；新配置的临时默认密码按你的要求设为 root。
- “后台密码来源”也可改为“我的 ROUTER_PASSWORD”，使用私有仓库 Secret；该模式要求至少 12 字符，最多 128 UTF-8 字节，不含冒号、换行或空字符。
- 原来的自动填写草稿会补上临时 root 默认值；已明确选择自定义密码的草稿保持原选择。导入旧记录不会偷偷改变其密码语义。
- x86 启动验收：本次选定的 EFI、Legacy、两种 VMDK 都须实际在隔离虚拟机启动并验证登录。
- 设备编译校验：用于其他型号，检查依赖、请求的软件、实际文件和 SHA256，识别压缩包与 OpenWrt 固件尾部；不声称设备已通过实机开机测试。
- 实验模式不执行启动验收。涉及正式交付或设备校验的配置要求私有仓库、密码和 HTTPS。

root 是临时默认密码，可首次登录后修改。项目不会替你改 GitHub Secrets，也不会自动刷机或修改家庭网络。

## 提交构建

已连接网页时，点击“构建新固件”直接提交；同一请求等待期间不会重复提交。

不输入网页令牌时，点击“查看 / 导出配置”，复制配置，再打开 GitHub 的 Run workflow，把配置粘贴到 config_json 后运行。不要留空，否则使用仓库示例配置。

自订文件包支持 ZIP / TAR.GZ / TGZ / 7Z，最大 12 MiB。按根目录结构覆盖文件；Kwrt 自订 IPK 必须匹配当前设备架构，包内安装脚本在设备首次启动时运行。核心包和内核模块仍从相同构建器的软件源选择。

PPPoE 可引用 PPPOE_USERNAME、PPPOE_PASSWORD；Wi-Fi 可引用 WIFI_PASSWORD。密码由本人在私有仓库设置，不要发送到聊天。

## 首页下载和本机校验

连接构建仓库后，首页“最近编译结果”显示最近成功任务。手动在 GitHub 运行的正常构建也会显示。首页结果与当前尚未提交的表单分开。

x86 的 EFI、Legacy、EFI VMDK、Legacy VMDK 分别下载；其他型号也逐个文件下载。GitHub 普通产物外面有一层 ZIP，每个固件 ZIP 仅含一个映像。日志与报告独立提供，无需下载所有格式。

页面显示大小、SHA256 和到期时间，可选择已经下载的 ZIP 或映像在本机校验，带进度和停止操作。文件不上传。旧构建 #5 已拆成私有 Release 中的四个单独文件；原始下载包保留。

普通产物保留七天。需要长期保留时，手动“收藏到私有仓库”；最多五版，项目不自动删除旧收藏。私有产物下载需登录 GitHub。

## 网页授权与异常

ChatGPT 的仓库连接不自动传给 Pages 网页。网页用自己的短期令牌，仅授权私有构建仓库，Actions 读写；上传文件或收藏还需 Contents 读写。令牌不进入网址、源码、模板、导出配置或浏览器存储。

刷新、关闭或点击断开会清除当前页面授权，GitHub 已受理的任务和定时检查继续运行。重新连接后读取原有记录，无需重新编译。

授权到期或权限不足时停止轮询并提示重连。遇到请求限流，按 GitHub 给出的恢复时间等待，多次限流进一步暂停。历史结果保留；网络超时先检查 GitHub 是否已经收到请求，系统不会自动重复提交。

## 上游更新

每天 04:23（北京时间 / 新加坡时间，GitHub 可能延迟）检查官方稳定版及 Kwrt 25.12 x86/64。更新通过构建、引导和登录回归后才批准，连接网页后载入批准版本，不覆盖正在编辑的配置。

其他平台本轮固定了构建器 SHA256 和软件索引指纹，上游变化则暂停相应构建。所有平台自动重新验证并发布更新仍未完成；任意内核、DTB 和实体设备刷机均不自动执行。

最新测试与已知问题见 [本轮报告](RELEASE-10.md)。
