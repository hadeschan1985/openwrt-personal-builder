# 安全与验收完善版

## 后台密码不再明文集成

构建主机通过 OpenSSL 的标准输入生成随机盐 SHA512-crypt 哈希；明文不进入命令参数、临时密码文件或平台生成的初始化脚本。首次启动只更新 root 的 shadow 密码字段，保留其他账号和字段，并限制 shadow 权限。哈希失败时停止，不回退到明文方式。

正式模式的 ROUTER_PASSWORD 要求至少 12 字符、最多 128 UTF-8 字节，不能有冒号、换行或 NUL。密码仍只由本人在私有仓库 Secrets 设置，网页和导出配置仅保存引用，不读取真实密码。

这不是“固件可以公开”：密码哈希也属于敏感数据；PPPoE、Wi-Fi、文件包和本人初始化脚本仍可能含私人内容。历史固件不会被改写或删除，只有新构建采用新处理。不会更改现有设备密码或自动刷机。

## 扩展正式验收

虚拟机校验改为使用完整的软件计划，覆盖功能开关自动加入的组件和自动移除项，而不只检查手工填写的软件包。增加子网掩码、WAN/LAN 映射、旁路由网关、DHCP、关闭 IPv6 的策略、防火墙后端；选择 Docker 时检查 daemon 能实际响应，不拉取外网镜像或连接真实设备。

Aria2 改为从本次已配置的 HTTPS 后台下载本地测试文件，不另行依赖 uhttpd，因此可验证 Nginx / Lighttpd 场景。自签名证书例外只用于已知隔离虚拟机的回环测试，不修改路由器设置或绕过浏览器安全警告。

定向真实测试采用官方 Nginx 与 Kwrt Lighttpd：Ext4、/25 管理网段、eth0 WAN / eth2 LAN、旁路由、关闭 DHCP 与 IPv6；Kwrt 还覆盖 iptables、Docker 和 USB 有线网卡组件。驱动存在不等于 USB 实物验证，Docker 响应不等于任意应用容器均已验证。

## 网页主动断开与旧请求隔离

连接后右上角增加“断开授权”。它清除本页令牌、构建/收藏等私有结果显示，并中止本页未完成的请求；未提交配置和当前文件选择保留。不会撤销账号中的 GitHub 令牌、删除历史、取消已受理的构建，或停止 GitHub 定时任务。

断开时正在提交的请求可能已被 GitHub 受理。重连后先查看记录，不自动重复提交。旧会话迟到的网络结果、JSON 解析结果和刷新收尾不能回写新会话；关闭连接弹窗也会清空未使用的令牌输入。

没有新增服务器、会员、付费资源、长期令牌或权限范围。页面按 Sites 本地预览和响应式流程验收，生产仍是 GitHub Pages + Actions。

技术依据：[OpenSSL 密码哈希工具](https://docs.openssl.org/3.0/man1/openssl-passwd/)。
