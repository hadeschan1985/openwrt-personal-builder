# 首页编译结果 · 2026-10-26

用户反馈 GitHub 构建成功但首页看不到结果。原因有两层：旧版结果只放在很下方的构建记录里；截图中的网页又未连接私有构建仓库，GitHub 本站登录不会自动授权给 Pages。

本次将“最近编译结果”放在设备表单上方，显示最近成功任务、时间、ZIP 大小、SHA256、到期时间和直接下载入口。新任务在运行/失败时保留上次成功结果；支持手动从 GitHub 提交的构建，不依赖网页请求编号。未授权、空记录、读取失败、产物到期/清理均有提示。

不修改构建脚本、账户授权、固件内容或保留时间，不发布私人固件，不保存访问令牌。结果通过已有 Actions 读取权限按会话查询，未将用户实际产物信息写进公开代码。

下载入口指向 GitHub 私有产物，仍需 GitHub 本站具备相应访问权限；大 ZIP 超过 256 MiB 时不会尝试整体读入浏览器校验，以免内存不足。ZIP SHA256 与解压后各映像的校验不同，页面明确区分。

本次只需要验证结果显示，不重复编译用户已有固件。代码测试为 JavaScript 30 项、Python 38 项；Windows 的 7-Zip 环境检查跳过一项，Linux 完整执行。发布与实际浏览器验收结果另记工作日志。
