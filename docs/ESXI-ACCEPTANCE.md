# 待提供环境后的 ESXi 验收

目前没有连接 ESXi，也没有创建服务器、虚拟机或修改任何家庭网络。现有 x86 云端 QEMU 引导和后台登录证据不冒充 ESXi 宿主机验收。

环境提供后，先只读确认宿主机版本、可用资源、数据存储及隔离测试网络，再按实际版本确定导入方式。不得覆盖现有虚拟机、磁盘或生产交换网络；测试资源统一使用独立名称和新建虚拟磁盘。

验收分别覆盖 EFI / Legacy、官方转换 VMDK 与 Kwrt 原生 descriptor + flat VMDK。检查镜像 SHA256、磁盘格式、启动方式、首次开机配置、网络接口顺序、HTTPS 后台密码登录及 RPC。重启后复查个人设置保留。记录实际宿主机版本、镜像摘要、虚拟硬件和结果。

不具备 USB/无线/蜂窝设备直通时，相关驱动仍只具备云端安装及依赖检查证据；没有代理节点时不声称真实线路连通。任何实体刷机或物理磁盘写入另行明确授权，不能混入虚拟机验收。
