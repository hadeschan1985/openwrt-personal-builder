已接入原站当前公开目录的 865 个 Kwrt 设备档案、24 个平台，以及独立的 OpenWrt 官方目录。N1 和玩客云的公开资源兼容修复已完成云端验证；修复由新验收版本启用，旧固定版本保留原状态。目录数量不是实体硬件实测数量。

最新逐型号检查完整结束：863 个公开非 x86 档案中，841 个默认组合通过、22 个默认组合失败；R3D 修正及玩客云单独通过，六个缺包型号的官方源替代也已实际编译。其余缺驱动/固件的型号保留明确失败，不删硬件组件凑成功。私有任务目前受 GitHub 账户限制，最后网页复验和最新私有批准尚未完成；详见本轮报告。

“电视盒子全系列”按型号自动绑定内核和 DTB。每日检查公开打包源码、内核产物与实际 DTB，经过代表组合真实打包、只读回读和模块版本检查后，才新增可选版本；历史配置继续使用原资源。最新型号、内核数量及验证范围以网页批准目录为准。Wavlink WL-WN573HX3 的 Kwrt 档案仍是 ROOTFS，网页另提供切换至官方完整升级镜像的入口。

新配置按使用者要求暂用 root / root；可改为私有仓库的 ROUTER_PASSWORD。x86 可逐个映像做虚拟机启动验收；其他设备执行编译及文件校验，界面明确标注未验证实机启动。

固件逐文件独立下载，首页显示私有构建结果、SHA256 和到期时间。令牌仅存在网页内存；授权失效停止自动读取，限流按 GitHub 响应等待，不自动重复提交构建。

自动跟进覆盖官方稳定版、Kwrt 当前发行系列和盒子独立内核资源。x86 通过虚拟机启动和登录后批准；其他平台逐平台实际编译和校验后批准。兼容的新发行系列建立独立候选并重新验收，未知结构保留旧版。每周逐型号编译只保存合成配置的检查报告。上游和验证规则均无变化时复用有效证据；切换版本由使用者决定。

成功的新构建在私有仓库归档实际软件输入，可从首页或历史记录发起断网重建。软件包版本必须与原记录一致；时间、随机字段及当前 Secret 值可能使映像字节不同。详情和存储上限见归档说明。

## 本地预览与检查

需要 Python 3.11+、Node.js 20+；实际 ImageBuilder 构建使用 Linux / Actions。

```powershell
python -m scripts.device_audit
python -m http.server 8765 --bind 127.0.0.1 --directory site
node --test tests/*.test.mjs
python -m unittest discover -s tests -p "test_*.py"
```

网页已包含完整且校验通过的固定快照，部署和本地预览无需读取滚动软件源。自动验收的新版本由私有仓库加载。历史交付说明保留在 docs/RELEASE-*.md，日期和测试数量只对应各自版本。
